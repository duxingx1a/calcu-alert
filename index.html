02 / Architecture

双层堆叠集成框架

研究使用大规模体检数据，构建双层堆叠集成模型，并通过概率校准将模型输出转译为更接近真实发生率的风险信息。

77 项输入特征常规体检、尿常规、血常规、肝功能、肾功能、血脂、人体测量、生命体征
→
10 个异质基模型LightGBM · XGBoost · CatBoost · GradientBoosting · LogisticRegression · GaussianNB · DecisionTree · RandomForest · AdaBoost · MLP
→
87 维元输入10 个 OOF 概率 + 77 项原始特征 → XGBoost 元学习器
→
Platt 校准输出校准后的阳性概率 + 87 维 SHAP 解释

5 折交叉验证 · 30% 测试集 · 基模型 OOF 概率保留不同学习器的互补信号

09 / Usage

安装与使用

本地运行

git clone https://github.com/duxingx1a/calcu-alert.git cd calcu-alert pip install -r requirements.txt python api_server.py

Docker 部署

docker build -t calcualert-api . docker run -d -p 5000:5000 calcualert-api

API 调用

curl -X POST https://api.ydl66.top/api/v1/predict \ -H "Content-Type: application/json" \ -d '{"features": {"Gender": 1, "Age": 45, ...}}'
